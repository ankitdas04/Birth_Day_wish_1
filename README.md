## 📖 Synopsis • プロット

> *"In a world full of billions of stars, one sleepy Little Snorlax brought endless warmth, smiles, and magic into my universe..."*

This repository houses a **multi-scene anime-inspired web experience**, lovingly crafted using pure web technologies and butter-smooth **GSAP** choreography. It takes the viewer on an emotional interactive journey through pastel dreamscapes, playful hidden surprises, warm reasons to cherish her, and an everlasting memory shrine.

```
 ╭─────────────────────────╮
 │  Act I: The Dream Portal│ ──► [ Typewriter Greeting & Aura Cursor ]
```

### 💫 Act I: The Awakening Portal (`#page-index`)
* **Dynamic Aurora Horizon**: Animated 400% gradient shifts between rose quartz, lavender, and morning glow.
* **Kawaii Custom Particle Wand**: Interactive cursor following your every touch.
* **Typewriter Magic**: A soft anime-dialogue greeting appearing character by character:
  > *"Hey You Know What! You're the most adorable human i ever met! 💖"*
* **Floating Stardust**: Whimsical emojis (`🌸`, `✨`, `💖`, `💫`, `💕`) floating gracefully through the cosmos.
* **Bouncing Portal Button**: Smooth GSAP entrance inviting the player to step forward.

### 💌 Act II: The Reasons of the Heart (`#page-cause`)
* **Magical Heart Cursor**: Bespoke SVG cursor with radiant drop-shadows.
* **The Shuffle Quest**: Clicking the sweet CTA button reveals beautiful heartfelt reasons one by one.
* **Hidden GIF Memories**: Hovering over any card unveils cute anime-style memory GIFs (`gif1.gif`, `gif2.gif`) tucked right beneath the text.
* **The Grand Teddy Hug**: Reaching the final reason summons a warm teddy hug illustration with sparkling victory text: *"You're the BESTEST ! 💖"*.
* **Storylane Unlock**: The button undergoes an anime power-up transition into **Story Mode** (`Enter Our Storylane 💫`).

### 🌌 Act III: The Eternal Memory Shrine (`#page-last`)
* **Sparkle Dust & Floating Heart Cascade**: Multi-layered backdrop with rising love hearts (`💝`, `💖`, `💗`, `💓`, `💕`) floating at distinct cinematic speeds.
* **Glassmorphic Photo Cards**: 3D hover elevations and reflective light sweep animations showcasing captured moments:
  * 📸 **Her Smile Says It All** (`pic 1.webp`)
  * 🌊 **Together Vibes** (`pic 2.webp`)
  * 🌸 **Pretty Soul** (`gif3.gif`)
* **The Heartbeat Vow**: Animated pulsing confession letter written straight from the heart.
* **Infinite Replay Loop**: Smooth fade-out restart button (`Love You Byeeeeeeee 💝`) to relive the experience again and again.

### 🪄 Magical Spellbook (Tech Stack)
* **Structure**: Semantic HTML5 with dynamic section switching.
* **Style Artistry**: 
  * Modern CSS3 Gradients & `@keyframes` (Breathing gradients, Heartbeat pulses, Sparkle dust layers).
  * Glassmorphism (`backdrop-filter: blur(10px)`).
  * Custom cursor blend-modes (`mix-blend-mode: difference`).
* **Motion Alchemy**: [GSAP (GreenSock Animation Platform) 3.12](https://greensock.com/gsap/) for smooth easing (`bounce.out`, `back.out`, `elastic.out`).
* **Calligraphy (Google Fonts)**:
  * `Dancing Script` (Romantic handwritten script)
  * `Quicksand` (Clean modern aesthetic)
  * `Bubblegum Sans` (Chibi anime game energy)
  * `Comic Neue` (Playful dialogue)

## 🎮 How to Summon (Quick Start) • 起動方法

No heavy node installations or compilers required! This pure frontend spell runs natively in any modern browser:

### 🌟 Option 1: Direct Double-Click
Simply open `index.html` in your favorite browser (Chrome, Edge, Safari, Brave, or Firefox).

### 🚀 Option 2: Live Server (Recommended for Best FPS)
If using VS Code or Antigravity IDE:
1. Install the **Live Server** extension.
2. Right-click [`index.html`](file:///e:/ALL%20PROJECT/Birthday%20wish%201/index.html) and select **"Open with Live Server"**.
3. Put on your headphones, play the recommended BGM, and enjoy!
